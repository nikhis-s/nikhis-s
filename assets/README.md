# Assets

## profile-header.svg

Custom header banner for the `nikhis-s` profile README.

- **Dimensions:** 1200 × 300 px
- **Palette:** deep navy background (`#0b1120` → `#161e33`), cyan/electric-blue accents (`#22d3ee`, `#3b82f6`)
- **Motifs:** subtle circuit traces and a central node diagram

### Editing

The SVG is plain XML with no external dependencies. Edit text, colors, or geometry directly in any text editor, then open it in a browser to preview. Keep the accessible `<title>` and `<desc>` elements in sync with any content changes.
